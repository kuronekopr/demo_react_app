# チャート生成の安定化：テンプレートライブラリ＋Claude Code スキル登録

## Context

現状の `runDualModelGeneration` は2段階LLMパイプラインで動作している：
- Stage 1: `gemma4:e4b` → メール本文生成（安定）
- Stage 2: `qwen2.5-coder:7b` → SVGチャートコード生成（**不安定** — 負の height、JSX/createElement混在、ラベルオーバーフローなど多数のバグが発生）

LLMにSVGをゼロから書かせるのをやめ、**事前に検証済みのテンプレート関数**からチャートコードを生成することで出力を100%安定化する。あわせて、チャートパターンをClaude Codeのプロジェクトスキル（スラッシュコマンド）として登録し、新パターンの追加・確認ができるワークフローを整える。

---

## 実装方針（3層構造）

### Layer 1: テンプレートライブラリ（新規ファイル）

**`src/services/chartTemplates.ts`** を新規作成。

TypeScript関数がデータを受け取り、完全なReactコンポーネントの**コード文字列**（`sanitizeCode` / `wrapWithEmail` に渡せる形式）を返す。SVGの座標計算はすべてTypeScript側で実行し、返却する文字列にはリテラル値のみが含まれる → LLMの計算ミスが入り込む余地がゼロになる。

```ts
export interface BarChartData {
  oldKwh: number;       // 旧型年間kWh  例: 2383
  newKwh: number;       // 新型年間kWh  例: 1922
  unitPrice: number;    // 円/kWh        例: 31
  savingsKwh: number;   // 年間節約kWh  例: 461
  savingsYen: number;   // 年間節約円   例: 14291
  roomSize: string;     // 畳数ラベル   例: "20畳"
}

export interface LineChartData extends BarChartData {
  oldMonthly: number[];  // 月別kWh 12点
  newMonthly: number[];  // 月別kWh 12点
}

export function buildBarChart(data: BarChartData): string { ... }
export function buildLineChart(data: LineChartData): string { ... }
```

**`buildBarChart` の内部ロジック:**
- `viewBox="0 0 560 240"`, `chartH=160`, `baseline=200`
- `maxVal = Math.ceil(data.oldKwh * 1.1 / 100) * 100`（常に正のスケール上限）
- `oldH = (data.oldKwh / maxVal) * chartH` を TypeScript で計算 → 文字列にリテラルで埋め込む
- `newH` も同様。**`y = baseline - barH`, `height = barH`** を確実にリテラル正値で出力
- 旧型バー: `x=160, width=80`, 新型バー: `x=320, width=80`
- Y軸グリッド4本 + kWhラベル、X軸ラベル、統計カード3枚

**`buildLineChart` の内部ロジック:**
- `padL=40, padR=20, padT=20, padB=30`, `usableW=500`
- `oldPts`/`newPts` を TypeScript 側で `{x, y}[]` として全計算
- `fillPts` 文字列も TypeScript 側で生成 → 返却コードに `.map()` 計算は一切含まれない
- `polyline points="x1,y1 x2,y2 ..."` のリテラル文字列のみ出力
- SVGオーバーフロー対策: 全点が `padL(40)〜540` の範囲内に収まることをTypeScript側で保証

参照ソース（ビジュアルの正解パターン）:
- `src/components/CodeInterpreter.tsx` の `BarComparisonDemo`（lines 83-116）
- `src/components/CodeInterpreter.tsx` の `LineGraphDemo`（lines 119-157）
